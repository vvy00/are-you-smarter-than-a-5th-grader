# Are You Smarter Than a 5th Grader?

This is a quiz game where you can find out if you are smarter than a 5th grader. It is built using HTML, CSS, and JavaScript.

## Features
- Levels (easy, medium, hard)
- Categories/subjects (math, english, history, geography, science, animals, space, health)
